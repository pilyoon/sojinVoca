# 소진보카 (PhotoVoca)

사진을 찍으면 그 안의 단어로 영단어 학습 카드를 만들어 주는 아이용 영단어 앱 (말해보카 스타일 웹앱).

- 사진 → Google Gemini(무료 키 사용 가능)로 단어 추출 → 단어장 저장
- 사진이 없으면 가장 최근 단어장으로 학습, 간격 반복(1·2·4·7·14일)
- 설정에서 Gemini API 키 입력 (브라우저 localStorage에만 저장)

정적 파일만으로 동작하므로 GitHub Pages로 그대로 배포됩니다.
HTML 뷰어 앱에서 쓰려면 모든 파일이 하나로 합쳐진 `sojinVoca.html` 한 개만 열면 됩니다.
